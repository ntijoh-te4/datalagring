= Utkast

Det här kapitlet samlar utkast på sektioner som ännu inte är inarbetade i bokens huvuddelar. Tanken är att läsa igenom dem och bestämma:

- Vilka som ska arbetas in (och i så fall var de passar bäst i bokens struktur).
- Vilka som ska skrivas om eller komprimeras innan de flyttas.
- Vilka som inte behövs.

Stilen, kodexempelmönstret (Ruby/Rails först, sen C# / EF Core) och pedagogiska tonen försöker matcha resten av boken.
